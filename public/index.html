Cheapest Bot

Which model gives the most for the money in Cursor right now, and how to launch it without getting billed for the fast variant. Open source, non-profit, nobody earns anything from it.

The trap. Launch composer-2.5 with only the model id and Cursor bills it as composer-2.5-fast: $3 in / $15 out per million tokens instead of $0.50 / $2.50. That's 6x on output. Confirmed by Cursor staff. Fix: pass fast=false. And always name the model: an unset model falls back to the default, which may be a pricey one.
Cursor's own models (Composer, Grok) come out of the plan's included allowance. Every other model bills credit at API list price from the first request.
